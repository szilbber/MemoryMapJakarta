# MemoryMapJakarta

Веб-приложение для хранения информации о людях и местах их захоронения. Проект разрабатывается в рамках практической работы по Jakarta EE.

## О проекте

MemoryMapJakarta позволяет хранить сведения о людях, включая имя, фамилию, даты рождения и смерти, описание и информацию о месте захоронения.

Проект реализуется с использованием трёхслойной архитектуры:

- **Слой представления** — сервлеты и JSP-страницы, отвечающие за взаимодействие с пользователем.
- **Слой бизнес-логики** — сервисы, реализующие операции с данными.
- **Слой доступа к данным** — JPA и PostgreSQL, используемые для хранения и обработки информации.
